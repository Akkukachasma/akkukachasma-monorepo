# Taste
- Writes and expects replies in Hinglish (romanized Hindi mixed with English); mirrors that style back rather than switching entirely to formal English. Heavily casual ("yaar", "hogya??", "yeara") even mid-deploy — match the informal tone, never over-formalize. Typo-heavy, run-together, space-less shorthand is the norm ("yad rkhan", "ye rha ssh access", "dpeloyed", "whrethis proect") — infer the intent, never correct the spelling or ask them to retype. Confidence: 0.85
- Wants the agent to actually bootstrap and run the project end-to-end and show it working (e.g. "chala ke dikhao"), not just make the file changes. Confidence: 0.6
- Asks short status questions ("check if both backend and frontend is running or not") and expects a definite verdict backed by real evidence (listening ports, running processes), not assumptions or a re-run of the setup. Confidence: 0.6
- Happy for the agent to launch dev servers when asked to run/verify them, but requires them torn down afterwards: kill every process it started, confirm the ports are free, and hand back the start command (e.g. `pnpm dev`) to run in their own new terminal. Never leave stray servers running. Asked for as one fixed sequence — "kill the ports where backend and frontend are running, check they are not busy, then give me the command to run it locally" — so fulfil it in exactly that order: list your background tasks, stop only the ones you started (never a process running the user's own dev server), print a per-port verdict (`3000: FREE` / `3001: BUSY -> 89813` from `lsof -ti:<port>` plus a `ps`/`cwd` sweep for leftover node/next procs), and close with the copy-pasteable start command for their own terminal. Confidence: 0.8
- Runs the local stack himself and will say so mid-task ("do not run anything locally, mein khud chalunga, just kill all ports"). Treat that as a hard boundary on the teardown turn: free the ports, attribute and kill only the app processes, then hand over commands — do not start a dev server, boot it, or curl-verify anything as a bonus, because that's the thing he just told you not to do. Confidence: 0.6
